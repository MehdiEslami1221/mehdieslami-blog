# نوشته‌های مهدی اسلامی

وبلاگ فارسی و انگلیسی با ظاهر هماهنگ وب‌سایت شخصی، میزبانی روی GitHub Pages و پنل مدیریت Sanity.

[وبلاگ فارسی](https://blog.mehdieslami.ir/) · [وبلاگ انگلیسی](https://blog.mehdieslami.ir/en/) · [پنل نوشتن](https://mehdi-eslami-blog.sanity.studio/) · [راهنمای فنی نگهداری](docs/MAINTENANCE.md)

## امکانات فعلی

- صفحهٔ مستقل برای هر مقاله با متن، تصویر، قطعه‌کد، برچسب و تنظیمات سئو.
- رابط فارسی و انگلیسی، جهت درست متن و فونت ایران‌سنس برای نوشته‌ها و برچسب‌های فارسی.
- جست‌وجو در عنوان، خلاصه، برچسب و نام دسته، همراه با فیلتر دسته‌بندی.
- ارتباط نسخه‌های ترجمه‌شده و نمایش متن اصلی در صورت نبود ترجمه.
- زمان تقریبی مطالعه، فهرست عنوان‌های مقاله و نوار پیشرفت خواندن.
- کپی پیوند در پایان مقاله، بدون تداخل با فوتر.
- حرکت ملایم تصویر دفتر و پس‌زمینهٔ کم‌رنگ و متحرک از صفر و یک، نشانه‌های کدنویسی و طرح یادداشت‌های وبلاگ.
- سایت‌مپ، اطلاعات ساختاریافته و خوراک RSS جدا برای هر زبان.
- خروجی چهار نوشتهٔ آخر برای نمایش خودکار در صفحهٔ اصلی وب‌سایت شخصی.

لایک و دیس‌لایک با سرویس جداگانهٔ Cloudflare Worker و دیتابیس D1 انجام می‌شود؛ آمار ترجمه‌ها مشترک است و ورود به حساب لازم نیست. ثبت، تغییر و حذف رأی پشتیبانی می‌شود. [راهنمای سرویس رأی‌دهی](docs/REACTIONS.md) روش راه‌اندازی و محدودیت‌ها را توضیح می‌دهد. نظر و پاسخ بدون ثبت‌نام نیز روی همان سرویس فعال است و پیش از نمایش به تأیید مدیر نیاز دارد. حساب بازدیدکننده و پنل اختصاصی انتشار پیاده‌سازی نشده‌اند. مدیریت محتوا از طریق Sanity انجام می‌شود. راهنمای فنی، ساختار فایل‌ها، ارتباط با سایت اصلی، محدودیت‌ها و موارد قابل بررسی پیش از تغییرات بعدی را توضیح می‌دهد.

## راه‌اندازی

Node.js نسخهٔ ۲۴ یا جدیدتر را نصب کنید و در پوشهٔ پروژه اجرا کنید:

```sh
npm ci
npm run dev
```

برای اجرای پنل در ترمینال جداگانه:

```sh
npm run studio:dev
```

پروژه به شناسهٔ `kaaepoyb` و دیتاست `production` متصل است. فقط نوشته‌های منتشرشده دریافت می‌شوند. خالی‌بودن دیتاست با صفحهٔ شروع نمایش داده می‌شود و مقالهٔ نمونه‌ای به سایت اضافه نمی‌شود.

## انتشار سایت

در تنظیمات مخزن، **Pages → Source** را روی **GitHub Actions** قرار دهید. سپس [صفحهٔ اجرای انتشار](https://github.com/MehdiEslami1221/mehdieslami-blog/actions/workflows/pages.yml) را باز کنید و از بالای فهرست اجراها، **Run workflow** را بزنید. شاخهٔ `main` را انتخاب کنید و دکمهٔ سبز **Run workflow** را بزنید. این صفحه در تب **Actions بالای مخزن** قرار دارد؛ منوی Actions داخل Settings صفحهٔ دیگری است. آدرس سایت در نتیجهٔ اجرای موفق نمایش داده می‌شود.

بعد از آماده‌شدن سایت، دامنهٔ `blog.mehdieslami.ir` را ابتدا در بخش **Custom domain** گیت‌هاب ثبت کنید؛ سپس در Cloudflare رکورد زیر را بسازید:

| گزینه        | مقدار                                  |
| ------------ | -------------------------------------- |
| Type         | CNAME                                  |
| Name         | blog                                   |
| Target       | MehdiEslami1221.github.io              |
| Proxy status | DNS only برای بررسی اولیه و صدور گواهی |
| TTL          | Auto                                   |

رکوردهای دامنهٔ اصلی را تغییر ندهید. بعد از تأیید دامنه، انتشار را دوباره اجرا کنید تا مسیرهای سایت بر اساس ساب‌دامنه ساخته شوند. گزینهٔ **Enforce HTTPS** را پس از فعال‌شدن انتخاب کنید.

## آماده‌کردن پنل برای موبایل

پنل در نشانی بالا منتشر شده است و ورود با حساب مجاز Sanity انجام می‌شود. نوشتن مقاله به انتشار دوبارهٔ پنل نیاز ندارد؛ بعد از تغییر ساختار فیلدها یا تنظیمات Studio، آن را دوباره منتشر کنید. برای راه‌اندازی اولیه یا انتشار دوباره از رایانه می‌توانید این دستورها را اجرا کنید:

```sh
npm ci
cd studio
npx sanity login
npm run deploy
```

روش دیگر، ساخت توکن انتشار در مدیریت پروژهٔ Sanity، ثبت آن در **GitHub → Settings → Secrets and variables → Actions** با نام `SANITY_AUTH_TOKEN` و اجرای workflow با نام **Deploy Sanity Studio** است. توکن را فقط در بخش Secrets وارد کنید؛ در فایل یا پیام عمومی قرار ندهید. آدرس پنل پس از انتشار موفق مشخص می‌شود.

## نوشتن مقاله

۱. دسته‌بندی‌ها را در پنل بسازید.
۲. یک **Post** ایجاد کنید، زبان را انتخاب کنید و عنوان و نشانی را وارد کنید.
۳. خلاصه، متن و در صورت نیاز تصویر، برچسب و تنظیمات سئو را تکمیل کنید.
۴. **Publish** را بزنید.

انتخاب زبان، ترجمهٔ خودکار انجام نمی‌دهد. برای مقالهٔ دوزبانه، دو نوشتهٔ جدا با زبان‌های فارسی و انگلیسی ثبت کنید. فیلد «نسخهٔ ترجمه‌شده» هر نوشته را به نسخهٔ مقابل متصل کنید تا اطلاعات زبان جایگزین در هر دو صفحه درج شود. هر دو نسخه باید منتشر شده باشند و تاریخ آینده نداشته باشند. تصویر می‌تواند مشترک باشد؛ متن، توضیح تصویر و تنظیمات سئوی هر زبان جدا ثبت می‌شود.

بدون تنظیم webhook، سایت در نوبت بعدی ساخت ساعتی به‌روز می‌شود؛ اجرای دستی هم ممکن است. برای اتصال انتشار مقاله به ساخت سایت، راهنمای [PUBLISHING.md](docs/PUBLISHING.md) را دنبال کنید. زمان‌بندی GitHub تضمین اجرای دقیق ندارد و در مخزن عمومیِ بدون فعالیت ممکن است پس از ۶۰ روز غیرفعال شود.

اگر دریافت محتوا خطا بدهد، انتشار جدید متوقف می‌شود تا نسخهٔ قبلی سایت حفظ شود. بعد از تغییر نشانی مقاله، آدرس قبلی خودکار به آدرس تازه هدایت نمی‌شود؛ نشانی مطالب منتشرشده را ثابت نگه دارید.

## بررسی پروژه

```sh
npm run typecheck
npm test
npm run studio:build
npm run build
```

خروجی سایت در `web/out` و خروجی پنل در `studio/dist` ساخته می‌شود. کد سایت در تولید به سرور اختصاصی نیاز ندارد؛ سهمیه‌های پلن رایگان Sanity و محدودیت‌های GitHub همچنان برقرارند.

## نمایش نوشته‌ها در هر دو زبان

نوشته‌های بدون ترجمه در هر دو رابط به زبان اصلی و با جهت درست نمایش داده می‌شوند. در صورت وجود نسخهٔ ترجمه‌شدهٔ منتشرشده و پیوندخورده، همان نسخهٔ متناسب با زبان رابط نمایش داده می‌شود. خروجی `latest-posts.json` اطلاعات عمومی چهار نوشتهٔ آخر را برای صفحهٔ اصلی وب‌سایت فراهم می‌کند. RSS همچنان بر اساس زبان خود مقاله‌ها تفکیک می‌شود.

تصویر دفتر یادداشت و پس‌زمینه، حرکت ملایم با CSS دارند و تنظیم کاهش حرکت سیستم را رعایت می‌کنند. دکمهٔ کپی پیوند در پایان مقاله و کنار بازگشت به نوشته‌ها قرار دارد تا روی لینک‌های فوتر نیفتد. اگر مرورگر اجازهٔ کپی ندهد، خود نشانی در همان بخش نمایش داده می‌شود.

بخش نظر و پاسخ بدون ثبت‌نام نیز روی همان سرویس Cloudflare فعال است و پنل مدیریت رمزی برای تأیید، رد و حذف از نمایش دارد. نام قابل ویرایش در همان مرورگر ذخیره می‌شود. برای جزئیات نگهداری و حذف نظر نامناسب، [راهنمای نظرها](docs/COMMENTS.md) را ببینید. ساختار پس‌زمینهٔ باینری، حرکت نرم کدها و یادداشت‌ها و محدودیت‌های آن در [راهنمای پس‌زمینه](docs/SPACE.md) ثبت شده است.
